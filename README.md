# Org Chart Builder

Interactive org chart builder - create, edit, and export org charts as PDF/PNG.

## Features
- Add people to the left, right, or underneath any position
- - Drag and drop to move people between roles
  - - Insert manager layers between existing positions
    - - Undo/redo all changes
      - - Auto-centering layout
        - - Export as PDF, PNG, or JSON
          - - Import previously saved charts
